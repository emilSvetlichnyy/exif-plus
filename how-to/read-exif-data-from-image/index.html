How to read EXIF data from an image

Six ways to read the EXIF in a photo, from a right-click to a command line.

Updated 2026-11-19

Direct answer: The fastest way on any device is to drop the file into a browser EXIF viewer. On a computer you can also use file properties (Windows) or Preview (Mac). On iPhone, use Photos for the basics or an app such as EXIF+ for the full list. For every tag, use ExifTool.

If the tool shows nothing

The photo may have had metadata removed (messengers and many sites do this), or it is a screenshot, or the tool cannot read HEIC. See HEIC vs JPEG metadata.

FAQ

How do I read EXIF data from a photo?

Use a browser EXIF viewer, your computer's file properties or Preview, an iPhone app, or ExifTool on the command line.

How can I see EXIF data without installing anything?

Use the browser viewer on this site; the file is read in your tab and not uploaded.

Why is the EXIF data empty?

It was stripped by an app or site, the file is a screenshot, or the viewer does not support the format.

Which tool shows the most tags?

ExifTool lists nearly every tag, including maker-specific ones.
