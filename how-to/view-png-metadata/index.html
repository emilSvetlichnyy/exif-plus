How to view PNG metadata

PNG files carry metadata in chunks. Many have none, and some carry EXIF.

Updated 2026-11-19

Direct answer: To view PNG metadata, drop the file into a browser metadata viewer or run ExifTool. PNG does not use JPEG's EXIF block by default; it stores text in tEXt, zTXt and iTXt chunks and can hold EXIF in an eXIf chunk. A plain PNG often shows little more than size, bit depth and colour type.

PNG chunkHolds
IHDRWidth, height, bit depth, colour type
tEXt / zTXt / iTXtText key-value pairs, such as Title, Author, Software, Comment
eXIfAn EXIF block, if the software wrote one
tIMELast-modified time, if present

How to look

  1. Open the browser metadata viewer and add the PNG (read locally in your tab).
  2. Or run exiftool image.png to list every chunk it understands.

Do PNGs hold location?

Only if an app wrote GPS into an eXIf chunk. Screenshots normally do not. Some AI image tools write text chunks describing the generation settings: see AI image metadata and C2PA. More: PDF, video and PNG metadata.

To strip PNG metadata, use the browser remover.

FAQ

Does PNG have EXIF data?

Only if the software that made it wrote an eXIf chunk. Many PNGs have none.

How do I view metadata of a PNG?

Use a browser metadata viewer or ExifTool.

Do PNG files contain GPS?

Rarely. Screenshots and exported graphics usually do not.

Can PNG hold text like a prompt or author?

Yes, in tEXt, zTXt or iTXt chunks, if an app writes them.
