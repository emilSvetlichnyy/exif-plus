How to remove photo metadata on Mac, Windows and Android

Each system can remove some metadata itself. A browser tool covers the rest on any device.

Updated 2026-10-12

Direct answer: On Windows use File Properties → Details → Remove Properties and Personal Information. On Mac, open the photo in Preview and remove location info in the Inspector. On any device, including Android, use the strip EXIF online tool to download a clean copy.

Windows

  1. Right-click the photo → Properties → Details.
  2. Click “Remove Properties and Personal Information”.
  3. Choose a cleaned copy or remove from the original, then confirm.

Mac

  1. Open the photo in Preview.
  2. Tools → Show Inspector → the GPS tab.
  3. Choose “Remove Location Info”, then save.

This targets location. For camera and other tags, use the browser tool.

Android and any browser

  1. Open strip EXIF online in your browser.
  2. Choose the photo (JPEG, PNG or WebP).
  3. Download the cleaned copy and share that one.

Processing stays in your browser tab. Check the result in the image metadata viewer. On iPhone see remove photo metadata on iPhone.

FAQ

How do I remove EXIF data on Windows?

Right-click the file → Properties → Details → Remove Properties and Personal Information.

How do I remove location from a photo on Mac?

Open it in Preview → Tools → Show Inspector → GPS tab → Remove Location Info.

How do I remove metadata on Android?

Use a browser-based EXIF remover to download a cleaned copy.

How can I confirm the metadata is gone?

Open the cleaned file in a metadata viewer.
