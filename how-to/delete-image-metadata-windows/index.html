How to delete image metadata on Windows

Windows can remove photo properties without extra software. Here are the steps and the limits.

Updated 2026-11-19

Direct answer: Right-click the photo, choose Properties → Details, click Remove Properties and Personal Information, then pick either a cleaned copy or removal from the original file. This works for common formats such as JPEG; always open the result to check.

Steps

  1. Right-click the image → Properties → Details tab.
  2. Click Remove Properties and Personal Information at the bottom.
  3. Choose Create a copy with all possible properties removed (safest), or Remove the following properties from this file and tick the ones you want gone (GPS, camera, dates).
  4. Click OK. A copy is saved next to the original with "- Copy" in the name.

Limits

  • Not every format or tag is covered; HEIC support depends on your codecs.
  • Batch: you can select several files before opening Properties.
  • To verify, reopen Details or use the browser viewer.

Alternatives

Use the browser EXIF remover for a quick clean without installing anything, or ExifTool for scripts: ExifTool commands. All platforms: remove metadata on Mac and Windows.

FAQ

How do I remove metadata from a photo in Windows 11?

Right-click the file, open Properties → Details, and choose Remove Properties and Personal Information.

Does Windows remove GPS from photos?

Yes, the Remove Properties dialog lets you remove location tags, if the format is supported.

Does it change the original?

Only if you choose to remove properties from the file itself; the copy option leaves the original untouched.

Can I clean many photos at once?

Yes, select them all before opening Properties.
