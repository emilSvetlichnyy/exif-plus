How to delete image metadata on Mac

macOS removes location easily; removing every tag needs another tool.

Updated 2026-11-23

Direct answer: On a Mac, open the photo in Preview → Tools → Show Inspector, go to the GPS tab and click Remove Location Info. In the Photos app, choose File → Export and untick the location option. These remove location; they do not clear camera and date tags.

Check what is left after cleaning

Open the new copy in the online EXIF viewer. If GPS Latitude and GPS Longitude are gone and the camera rows are empty, the clean worked. To see what a photo reveals first, read how to check EXIF data.

If the photo came from an iPhone, you can clean it on the phone instead: EXIF+ saves a cleaned copy and keeps the original. See remove photo metadata on iPhone and Mac and Windows overview.

FAQ

How do I remove location from a photo on Mac?

Preview → Tools → Show Inspector → GPS tab → Remove Location Info.

Does Preview remove all metadata?

No. It removes location; camera and date tags remain.

Can Photos export without location?

Yes. Untick the location option in the export dialog.

How do I remove everything?

Use a metadata remover such as the browser tool here or ExifTool.
