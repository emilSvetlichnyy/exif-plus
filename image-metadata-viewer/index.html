Direct answer: An image metadata viewer lists the hidden data stored inside an image file — mostly EXIF (camera, date, GPS), sometimes IPTC (author, caption, copyright). Choose a file above and the fields are read in your browser tab.

How do I check image metadata location?

Look for GPS latitude and longitude in the results. If they are present, anyone who gets the original file can place the photo on a map. If they are missing, location services were off, or an app already removed them.

How do I remove image metadata?

Use strip EXIF online for a clean download, or remove GPS only. On iPhone, remove photo metadata from your library with EXIF+.

Which file types work?

JPEG, PNG and WebP in the browser. HEIC from an iPhone is often not decodable in browsers — use the HEIC metadata workflow in the app. Metadata inside PDFs and videos is outside this tool: see PDF, video and PNG metadata.

FAQ

How do I check image metadata?

Open this page, choose a JPEG, PNG or WebP, and read the listed fields. Processing stays in your browser tab.

Can image metadata show where a photo was taken?

Yes, if GPS coordinates are stored in the file. Many phone photos include them unless location was off or they were stripped.

How do I remove metadata from an image?

Use the EXIF remover on this site for a cleaned download, or EXIF+ on iPhone for Photo Library items.

Is image metadata the same as EXIF?

EXIF is the most common kind. IPTC (captions, author, copyright) can also be present in the same file.

Are my images uploaded?

Not to our servers for this tool: the file is read locally in your browser.

Need this on iPhone?

EXIF+ views, edits, and removes EXIF/IPTC metadata — including GPS — on-device. Single-photo clean and edit are available to start; Premium unlocks multi-select batch tools and share-without-metadata. Cleaned photos are saved as new Photo Library items (originals stay).
