What is GPS metadata?

GPS metadata — also called geotags or photo location data — records where a photo was captured, usually as latitude and longitude.

Direct answer: GPS metadata is location information embedded in a photo file. If someone opens the original with an EXIF viewer, they can often see exactly where it was taken.

How geotags get into photos

When Location Services are on, phones write coordinates into the image. Camera originals often include GPS; screenshots and some re-exports may not.

GPS metadata vs “location” in Photos

Embedded GPS tags live inside the file. Apple Photos may also show places using library databases. Cleaning the file removes embedded tags from that copy; it is the reliable control before you share an original.

Privacy risk

A single geotagged photo can reveal home addresses, schools, hotels, or workplaces. That is why “remove GPS from photo” and “remove geotag online” are common searches.

FAQ

What is GPS metadata in a photo?

It is embedded location data — typically latitude, longitude, and sometimes altitude or a GPS timestamp — stored with the image file.

Is GPS metadata the same as a geotag?

Yes for most everyday use. Geotag usually means those embedded coordinates.

Does turning off location for Camera stop old geotags?

It stops new ones. Old photos may still contain GPS until you remove metadata.

Can someone see my home from one photo?

If the original still has precise GPS tags, yes — that is the core risk of sharing uncleaned camera originals.

Does removing GPS delete the picture?

No. Cleaning creates a new file (or a new library item in EXIF+) without those location tags.
