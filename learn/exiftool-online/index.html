ExifTool online: what to use instead

ExifTool itself runs on your computer. For quick jobs in a browser there are online viewers; for full control, learn four commands.

Updated 2026-11-19

Direct answer: ExifTool, written by Phil Harvey, is a free command-line program for reading and writing metadata in many file types. It is not an online service. If you want something in a browser, use an online metadata viewer such as the one on this site, which reads JPEG, PNG and WebP in your tab without uploading them.

Four commands worth knowing

GoalCommand
View all tagsexiftool photo.jpg
Remove all metadataexiftool -all= photo.jpg (keeps a _original backup)
Remove GPS onlyexiftool -gps:all= photo.jpg
Clean a whole folderexiftool -r -all= folder/

Removing all tags can also drop the orientation and colour profile, so a photo may look rotated or slightly different afterwards. Test on a copy first.

Browser or app instead

  • Browser: EXIF viewer, EXIF remover, GPS remover.
  • iPhone: EXIF+ for photos in your library; HEIC is supported.

FAQ

Is there an ExifTool online?

ExifTool is a command-line program. Online viewers offer a similar view for common formats.

Is ExifTool free?

Yes, it is free and open source.

How do I remove all metadata with ExifTool?

Run exiftool -all= followed by the file name. It keeps a backup copy with _original in the name.

Is an online tool safe for private photos?

Pick one that processes files in your browser, as the viewer here does, rather than uploading them.
