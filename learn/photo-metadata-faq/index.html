Photo metadata FAQ

Twelve questions people ask most, each answered in two sentences or less.

Updated 2026-11-27

What is photo metadata?

Data stored inside an image file that describes it: camera, settings, date and sometimes location. The main standards are EXIF and IPTC.

What is EXIF?

A tag block written by cameras and phones that records device, shot settings, time and, if enabled, GPS. See what is EXIF.

Do photos contain my location?

Only if Location Services was on for the camera app. Check with this guide.

How do I see a photo's metadata on iPhone?

Swipe up in Photos for basics, or use an app for the full list. Steps: view EXIF on iPhone.

How do I remove metadata on iPhone?

Use an app that saves a cleaned copy, such as EXIF+, or turn off Location in the share sheet for a single send. See remove photo metadata on iPhone.

Does removing metadata change the picture?

Not visibly in normal use, but the file is rewritten and may be recompressed. See does cleaning reduce quality.

Do screenshots have EXIF?

Usually very little and no GPS. See screenshot metadata.

Do messengers and social apps strip it?

Often from the displayed copy, rarely from files sent as documents. See which apps remove metadata.

Is HEIC different from JPEG for metadata?

Both store EXIF and GPS; the container differs. See HEIC vs JPEG metadata.

Do social networks remove it for me?

It depends on the service and how you send the file. See does X (Twitter) strip EXIF data and which apps remove photo metadata.

Can I edit metadata instead of deleting it?

Yes: date, location, camera and author fields can be changed. See remove vs edit.

What is the difference between EXIF and IPTC?

EXIF is mostly technical and device-written; IPTC holds descriptive and rights text such as caption and copyright. See EXIF vs IPTC.

Is there a free way to do this?

Yes: the browser viewer, the browser remover, and single-photo remove in the app. Batch needs Premium, see free vs Premium.

FAQ

What is photo metadata?

Data stored inside an image file that describes it, such as camera, settings, date and sometimes location.

Can photo metadata reveal where I live?

Yes, if the original file has GPS tags from photos taken at home and you share it unchanged.

How do I remove metadata from photos?

Use a metadata remover: the browser tools on this site, or EXIF+ on iPhone.

Do I lose the original when I clean a photo?

Not in EXIF+: cleaned photos are saved as new Library items and the original is kept.

Need this on iPhone?
