PDF, video and PNG metadata: what each stores

Metadata is not only for photos. PDFs, videos and PNGs carry their own fields — here is what is in each and where it fits with EXIF+.

Updated 2026-10-12

Direct answer: JPEG photos mainly use EXIF/IPTC; PNG uses text chunks (and sometimes EXIF); PDFs store document properties such as author, title and creation tool; videos store container tags such as creation time and sometimes location. The tools on this site read images; they do not read PDFs or video.

JPEG, HEIC, WebP

Camera, date and GPS in EXIF; captions and copyright in IPTC. Check with the image metadata viewer.

PNG

PNG has no standard camera EXIF block in most files, but can hold text chunks and, in some files, EXIF. Screenshots and generated images are often PNG: see screenshot metadata and AI image metadata.

PDF

Open the document properties in your PDF reader to see author, title, creation tool and dates. EXIF+ and the browser tools here do not process PDFs.

Video

Videos can store creation time and, from phones, sometimes location. EXIF+ does not edit video metadata.

FAQ

How do I view PDF metadata?

Open Document Properties in your PDF reader to see author, title, creation tool and dates.

Does PNG have EXIF?

Not usually in the camera sense. It can have text chunks and, in some files, an EXIF block.

Does EXIF+ edit video metadata?

No. EXIF+ works on photo metadata (EXIF, IPTC, GPS).

Which tool should I use for photos?

The image metadata viewer here for desktop files, or EXIF+ on iPhone.

Need this on iPhone?

EXIF+ views, edits, and removes EXIF/IPTC metadata — including GPS — on-device. Single-photo clean and edit are available to start; Premium unlocks multi-select batch tools and share-without-metadata. Cleaned photos are saved as new Photo Library items (originals stay).
