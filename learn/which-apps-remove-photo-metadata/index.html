Which apps remove photo metadata?

Many apps re-encode photos and drop EXIF/GPS from the copy others see — but none is a guarantee. Here is how the common ones compare and where the risk is.

Updated 2026-11-12

Direct answer: Several big apps re-encode photos you upload, which often removes EXIF and GPS from the shared copy. Sending the same photo as a file or document usually keeps the original bytes and metadata. Because behavior varies by app version and route, remove metadata yourself before sharing.

Clean first, then any route is safe

If you remove metadata in EXIF+ before sending, the route no longer matters. From the app's code:

  • Remove Metadata decodes the photo and writes a new image file that carries only the orientation tag: no EXIF, GPS, IPTC, camera make or model.
  • The cleaned file is saved as a new photo in your library with no location attached; the original is not changed. In Photos it appears with the date you cleaned it.
  • Share inside EXIF+ (Premium) sends that same cleaned file through the iOS share sheet.

So whether you then send it as a photo, a file, a document or an email attachment, there is no GPS in the file left to keep. One thing cleaning cannot cover: an app that adds your current location to a post when you allow it, which is a setting of that app, not data in the photo.

FAQ

Which apps remove EXIF from photos?

Many social apps re-encode uploads, which often drops EXIF and GPS from the public copy. Behavior is not guaranteed and differs by route (photo vs file).

Does sending a photo as a file keep metadata?

Usually yes, because file or document sends tend to preserve the original bytes.

Do these apps see my photo's location?

Assume the service receives the original upload with its metadata, even if the copy others see is cleaned.

What is the safest approach?

Remove metadata yourself before sharing, then check the result with a metadata viewer.

Which apps officially say they remove photo location?

Very few document it. Apple says shared photos may include location unless you turn it off in the share sheet Options; a 2018 Signal for iOS change strips metadata from image attachments. Most other apps publish no statement.
