Does Telegram remove EXIF?

Telegram has two ways to send a picture: as a compressed photo or as an uncompressed file. They treat metadata very differently.

Direct answer: A normal Telegram photo send is compressed, which usually drops EXIF and GPS. Sending the picture as a file (uncompressed) delivers the original bytes — including camera tags and location — to everyone in the chat.

Photo send vs file send

  • Compressed photo: re-encoded for size; EXIF/GPS usually gone for recipients.
  • Send as file / without compression: original file; EXIF, GPS, date, and device model usually kept.
  • Channels and bots: behavior depends on how the image was posted — do not assume one rule.

Why this matters

People often choose “file” to keep full quality — exactly the mode that keeps GPS metadata. A home or office location can travel with the photo.

Safe workflow

Clean first, then send in any mode: use the remove GPS tool or the metadata cleaner in your browser, or remove location on iPhone with EXIF+. Check the result with the EXIF viewer.

Other platforms: WhatsApp, Discord, Instagram, iMessage & AirDrop.

FAQ

Does Telegram remove EXIF data?

Usually yes for compressed photo sends, because Telegram re-encodes them. Files sent without compression keep the original EXIF and GPS.

Does Telegram remove location from photos?

Compressed photos usually lose GPS tags. Uncompressed “send as file” keeps them. Remove location yourself before sending if it matters.

Is sending as a file on Telegram safe for privacy?

Not by default — the recipient gets the original file with its metadata. Strip EXIF/GPS first, then send as a file if you need full quality.

How do I check if a Telegram photo still has EXIF?

Download the received file and open it in an EXIF viewer. If you see GPS or camera fields, the metadata survived.
