HEIC vs JPEG metadata

Both formats store EXIF and GPS, so both can leak your location. The difference is the container, and which tools can read it.

Updated 2026-11-27

Direct answer: Yes. A HEIC photo from an iPhone carries EXIF, including GPS, just like a JPEG. JPEG keeps EXIF in an APP1 segment at the start of the file; HEIC (an HEIF file) keeps it as a separate metadata item inside the container. Many older tools read JPEG but not HEIC, which is why a tool can say a HEIC photo has no metadata when it does.

What this means in practice

  • Switching an iPhone to JPEG does not remove location; both formats record it if Location Services is on for the camera.
  • The browser viewer and browser remover work best on JPEG, PNG and WebP; HEIC may be unsupported in some browsers. See HEIC metadata.
  • EXIF+ reads HEIC from the Photo Library and can keep HEIC or HEIF when it saves the cleaned copy.

FAQ

Does HEIC have EXIF data?

Yes. HEIC photos carry EXIF, including GPS, stored as a metadata item in the HEIF container.

Is HEIC safer for privacy than JPEG?

No. Both record location when Location Services is on for the camera.

Why can't my tool read HEIC metadata?

Many older or browser-based tools do not parse the HEIF container, so they report nothing.

Does converting HEIC to JPEG remove metadata?

Not necessarily. Many converters copy the EXIF across, so check the result.
